什麼是 SamRewritten？

SamRewritten 是一款工具，可讓你在 Steam 帳號上解鎖與重新鎖定成就。 它也能編輯開放統計資料的遊戲與 App。雖然成就本身沒有金錢價值， 但它們廣泛用於展示收集進度與炫耀成果。SamRewritten 同時提供精緻的 GTK 圖形介面與可編寫指令碼的命令列工具。

功能特色

  • 只需點一下即可鎖定與解鎖特定成就
  • 針對全部或選定的 App 批次鎖定／解鎖成就
  • 在自訂的時段內排程成就解鎖
  • 複製其他使用者的解鎖時間並在你的帳號上重現
  • 即時編輯遊戲統計資料
  • 支援單一 App 或批次匯入／匯出成就與統計資料（JSON）
  • 掛機（偽裝遊戲中）：在你關閉前持續顯示為遊戲中
  • 淺色與深色主題
  • 除英文外，還支援法文、西班牙文、日文與巴西葡萄牙文
  • 功能完整、不需要 GTK 的 CLI（使用說明，英文）

SamRewritten 的翻譯皆由社群貢獻，但目前尚未有人提交中文翻譯。你不需要是程式設計師也能協助——翻譯大多只是填寫一個文字檔而已。歡迎任何語言的貢獻，請參閱翻譯指南開始參與。

安裝

Windows

從 Releases 頁面 下載官方安裝程式，然後從開始功能表啟動 SamRewritten。另有提供可攜式 ZIP。

Linux

SamRewritten 可在每一種 Linux 發行版上執行 —— 以 AppImage、透過 Snap Store，或從 AUR 安裝。請參閱 安裝說明 以選擇最適合你發行版的方式。

常見問題

SamRewritten 可以在 Linux 上執行嗎？

可以。它提供 Linux AppImage，並已上架 AUR（samrewritten-git）。它支援 Snap 版 Steam、 Ubuntu／Debian 多架構與 .deb 安裝，以及使用 Steam runtime 的發行版，例如 Gentoo 和 Arch。

什麼是 Steam 成就管理器？

Steam 成就管理器（SAM）可讓你在 Steam 帳號上解鎖與重新鎖定成就，並編輯 遊戲統計資料。SamRewritten 是一款現代化、開放原始碼的 SAM，支援 Linux 與 Windows。

SamRewritten 是免費且開放原始碼的嗎？

是的 —— 它是免費且開放原始碼的，並託管於 GitHub。它與 Valve Corporation 或 Microsoft 沒有任何關聯。

SamRewritten 支援 Flatpak 版的 Steam 嗎？

支援。SamRewritten 可搭配 Flatpak 版的 Steam 使用。Snap 與 .deb 安裝的 Steam 同樣受到支援。

我可以透過命令列使用 SamRewritten 嗎？

可以。CLI 不需要 GTK，可列出 App／成就／統計資料、批次鎖定／解鎖、 編輯統計資料、匯入／匯出 JSON，以及掛機（偽裝遊戲中）。每個指令都以 JSON 輸出，方便編寫指令碼 —— 完整的指令參考請見 CLI 使用說明（英文）。
